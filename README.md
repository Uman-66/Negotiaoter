# The Negotiator

Voice agents that call, compare, and haggle — ElevenLabs challenge, Hack-Nation 6th Global AI Hackathon. Vertical: **home cleaning**. Full plan in [PLAN.md](PLAN.md).

## Team roles

| Who | Role | Owns |
|-----|------|------|
| A (frontend) | Dashboard | `frontend/` — intake/spec confirmation, live call board, ranked report |
| B | Backend/orchestrator | `backend/`, tool endpoints (`log_quote_item`, `get_best_bid`, `log_outcome`), red-flag + ranking engine |
| Alex (phone-based) | Conversation design + ElevenLabs config | `prompts/`, `personas/`, `verticals/`, `evals/`, `demo/`, `docs/`, EL dashboard, credit chase |
| D | Voice integration + doc intake | EL tool wiring, web-call sessions, photo/PDF → job spec |

## Hard rules (agreed hour 0)

1. **Prompts are files.** Agents load system prompts from `prompts/` and config from `verticals/` — never hardcoded. Alex iterates on these from a phone; a merged PR changes agent behavior with zero code.
2. **Schemas are the contract.** `schemas/job_spec.schema.json` and `schemas/quote.schema.json` — both intake paths produce the former, every call produces exactly one of the latter.
3. **Backend is publicly reachable by hour 6** (deploy or ngrok) so ElevenLabs tool calls and phone-side testing work. Localhost-only blocks half the team.
4. **Voice minutes are the scarce resource.** Iterate in text mode against `personas/` + `evals/golden-calls.md` first; dial only to verify.

## Repo layout

```
prompts/      system prompts for interviewer & caller agents
personas/     role-player cards (hidden floors + concession rules)

evals/        golden-call checklist, run before burning minutes
demo/         demo script + success-criteria mapping

```

## Schemas (The Contract)

### 1. Job Specification Schema (`schemas/job_spec.schema.json`)
This schema defines the structured job specification generated by the voice interview and document intake, confirmed by the user.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "JobSpec",
  "description": "One structured cleaning job spec, confirmed by the user, reused verbatim on every call.",
  "type": "object",
  "required": ["property", "clean_type", "frequency", "condition", "add_ons", "access", "schedule", "confirmed_by_user"],
  "properties": {
    "property": {
      "type": "object",
      "required": ["type", "sqft", "bedrooms", "bathrooms", "levels"],
      "properties": {
        "type": { "enum": ["apartment", "house", "condo", "townhouse"] },
        "sqft": { "type": "integer" },
        "bedrooms": { "type": "integer" },
        "bathrooms": { "type": "number" },
        "levels": { "type": "integer", "default": 1 }
      }
    },
    "clean_type": { "enum": ["standard", "deep", "move_out"] },
    "frequency": { "enum": ["one_time", "weekly", "biweekly", "monthly"] },
    "condition": {
      "type": "object",
      "required": ["clutter_level", "has_pets", "weeks_since_last_clean"],
      "properties": {
        "clutter_level": { "enum": ["low", "medium", "high"] },
        "has_pets": { "type": "boolean" },
        "weeks_since_last_clean": { "type": "integer" }
      }
    },
    "add_ons": {
      "type": "object",
      "properties": {
        "fridge": { "type": "boolean", "default": false },
        "oven": { "type": "boolean", "default": false },
        "windows": { "type": "boolean", "default": false },
        "baseboards": { "type": "boolean", "default": false },
        "laundry": { "type": "boolean", "default": false }
      }
    },
    "access": {
      "type": "object",
      "required": ["parking", "entry_method", "walk_up_floor"],
      "properties": {
        "parking": { "enum": ["street", "driveway", "garage", "metered"] },
        "entry_method": { "type": "string" },
        "walk_up_floor": { "type": "integer", "default": 0 }
      }
    },
    "schedule": {
      "type": "object",
      "required": ["preferred_date", "preferred_time_window"],
      "properties": {
        "preferred_date": { "type": "string", "format": "date" },
        "preferred_time_window": { "type": "string" },
        "flexibility": { "type": "string" }
      }
    },
    "open_questions": { "type": "array", "items": { "type": "string" } },
    "confirmed_by_user": { "type": "boolean" },
    "intake_source": { "enum": ["voice_interview", "document", "both"] }
  }
}
```

### 2. Quote Schema (`schemas/quote.schema.json`)
This schema defines the structured outcome of a call with a cleaning provider.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "Quote",
  "description": "One structured call outcome for home cleaning. Every call produces exactly one of these.",
  "type": "object",
  "required": ["company", "call_id", "outcome"],
  "properties": {
    "company": { "type": "string" },
    "call_id": { "type": "string" },
    "outcome": { "enum": ["quote", "callback", "declined"] },
    "pricing_model": { "enum": ["flat", "hourly"] },
    "line_items": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["label", "amount"],
        "properties": {
          "label": { "type": "string" },
          "amount": { "type": "number" },
          "disclosed_voluntarily": { "type": "boolean", "default": true },
          "negotiable": { "type": "boolean", "default": false }
        }
      }
    },
    "opening_total": { "type": "number" },
    "final_total": { "type": "number" },
    "total": { "type": "number" },
    "moved_because": { "type": "string", "description": "Reason for price movement" },
    "conditions": { "type": "array", "items": { "type": "string" } },
    "red_flags": { "type": "array", "items": { "type": "string" } },
    "red_flag_reasons": { "type": "array", "items": { "type": "string" } },
    "callback": {
      "type": "object",
      "properties": {
        "contact_name": { "type": "string" },
        "window": { "type": "string" }
      }
    },
    "transcript_url": { "type": "string" },
    "recording_url": { "type": "string" }
  }
}
```
