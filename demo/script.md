# Demo Script (~3 min) — each beat maps to a success criterion

1. **The problem (20s).** Cleaning quotes are hard to compare: different scopes, hidden add-ons, and low introductory prices. Nobody has time to call every cleaner and decode the fees. Our agent does. → *provable pain*
2. **Intake (30s).** Show a cleaning quote or room photo producing a draft job spec; the user corrects it and confirms before any call. The voice interviewer produces that same schema. → *both intake paths, one confirmed spec*
3. **The calls (45s).** Live call board: three calls against three personas (tough negotiator, lowballer, upseller), quote line items streaming in as the agent logs them mid-call. → *3 negotiation styles, structured itemized quotes*
4. **The money moment (45s, played aloud).** The agent cites the current itemized competing bid; a cleaner drops an add-on or final price. Replay the honest "are you a robot?" exchange here. → *price moves from gathered leverage; disclosure holds*
5. **The report (40s).** Ranked comparison: a lowballer is flagged for an implausibly cheap cleaning quote or hidden fees; the recommended deal explains why and links to the recording/transcript if captured. → *ranked, evidence-backed recommendation*

Close: "Swapping cleaning for another service vertical means swapping the config and prompts, not rebuilding the call flow." Show `verticals/` for 5 seconds.
