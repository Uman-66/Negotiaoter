2. **Intake (30s).** Clip of the voice interview building the spec; then the same spec produced from an uploaded photo/existing quote. User confirms it on screen. → *both intake paths, one confirmed spec*
3. **The calls (45s).** Live call board: three calls against three personas (tough negotiator, lowballer, upseller), quote line items streaming in as the agent logs them mid-call. → *3 negotiation styles, structured itemized quotes*
4. **The money moment (45s, played aloud).** The agent cites the $1,850 competing bid; Mike drops from $2,400 to $1,950. Replay the "are you a robot?" exchange here. → *price moves from gathered leverage; disclosure holds*
5. **The report (40s).** Ranked comparison: lowballer flagged (-48% + hidden fees + cash deposit), recommended deal explained in plain language with a clickable transcript citation. → *ranked, evidence-backed recommendation*
